# Amazon India: A Decade of Sales Analytics

## Project Overview
This project analyzes Amazon India sales data from 2015 to 2025 to understand sales trends, customer behavior, product performance, and payment preferences.

## Dataset
- Sales transaction data from 2015 to 2025
- Product catalog: 2,004 records
- Total transactions: 1,127,609

## Tools and Technologies
- Python
- Pandas
- SQL
- SQLite
- Streamlit
- Jupyter Notebook
- Git and GitHub

## Key Metrics
- Total Revenue: ₹76,888,729,563.25
- Total Transactions: 1,127,609
- Units Sold: 1,409,582
- Unique Customers: 354,969

## Dashboard
The Streamlit dashboard displays key metrics, yearly sales trends, category revenue, and payment method analysis.

## How to Run
Install the required packages:

    pip install pandas streamlit

Start the dashboard:

    python -m streamlit run app.py
